Baseline Models

Five baselines from the RF drone-detection literature were implemented in src/models/baselines.py and src/models/fgcs_faithful_dnn.py. Where the authors released code, the code was treated as the primary reference; discrepancies with the paper text are documented. All models are instantiated by name through get_model() in src/models/model_factory.py.

1. FGCS2019DNN (Al-Sa’d et al., 2019)

M. F. Al-Sa’d et al., “RF-based drone detection and identification using deep learning approaches: An initiative towards a large open source drone database,” Future Generation Computer Systems, vol. 100, pp. 86–97, 2019.

A fully connected network operating on the 2048-bin stitched L/H power spectrum. The paper text and the authors’ released code describe different hidden-layer widths; both variants were implemented and the code variant is used as the primary faithful reproduction.

2. MC1DCNN / Baseline1DCNN (Allahham et al., 2020)

M. S. Allahham et al., “Deep Learning for RF-Based Drone Detection and Identification: A Multi-Channel 1-D Convolutional Neural Networks Approach,” Proc. IEEE ICIoT, pp. 112–117, 2020.

A multi-channel 1-D CNN in which each input channel is a 10 MHz sub-band of the power spectrum, allowing the convolutional filters to learn band-specific patterns.

Input (8, 256)
Conv1d(8 -> 32, k=11, s=2, p=5) + ReLU -> MaxPool1d(2)
Conv1d(32 -> 64, k=5, s=1, p=2) + ReLU -> MaxPool1d(2)
Flatten (2048) -> Linear(2048 -> 128) + ReLU -> Linear(128 -> 4)
