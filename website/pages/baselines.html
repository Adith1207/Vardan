Baseline Models

Five baselines from the RF drone-detection literature were implemented in src/models/baselines.py and src/models/fgcs_faithful_dnn.py. Where the authors released code, the code was treated as the primary reference; discrepancies with the paper text are documented. All models are instantiated by name through get_model() in src/models/model_factory.py.

1. FGCS2019DNN (Al-Sa’d et al., 2019)

M. F. Al-Sa’d et al., “RF-based drone detection and identification using deep learning approaches: An initiative towards a large open source drone database,” Future Generation Computer Systems, vol. 100, pp. 86–97, 2019.

A fully connected network operating on the 2048-bin stitched L/H power spectrum. The paper text and the authors’ released code describe different hidden-layer widths; both variants were implemented and the code variant is used as the primary faithful reproduction.

2. MC1DCNN / Baseline1DCNN (Allahham et al., 2020)

M. S. Allahham et al., “Deep Learning for RF-Based Drone Detection and Identification: A Multi-Channel 1-D Convolutional Neural Networks Approach,” Proc. IEEE ICIoT, pp. 112–117, 2020.

A multi-channel 1-D CNN in which each input channel is a 10 MHz sub-band of the power spectrum, allowing the convolutional filters to learn band-specific patterns.

Input (8, 256)
Conv1d(8 -> 32, k=11, s=2, p=5) + ReLU -> MaxPool1d(2)
Conv1d(32 -> 64, k=5, s=1, p=2) + ReLU -> MaxPool1d(2)
Flatten (2048) -> Linear(2048 -> 128) + ReLU -> Linear(128 -> 4)
Trainable parameters: 275,940

Cross-entropy
Optimiser
Adam, learning rate 0.001

Non-overlapping (the paper discusses both overlapping and non-overlapping filter banks)

scripts/train_baseline1dcnn_faithful_reproduction.py

3. DSCNN – Depthwise Separable CNN (Medaiyese et al., 2021)

O. Medaiyese, A. Syed and A. P. Lauf, “Machine Learning Framework for RF-Based Drone Detection and Identification System,” Proc. ICON-SONICS, pp. 1–6, 2021.

A lightweight network that operates directly on the normalised raw waveform, using a depthwise separable convolution to reduce parameters and computation.

Input (1, 2048)
Conv1d(1 -> 32, k=11, s=2, p=5) + ReLU
Depthwise Conv1d(32 -> 32, k=5, groups=32) -> Pointwise Conv1d(32 -> 64, k=1) + ReLU
MaxPool1d(4) -> Flatten (16,384) -> Linear(16,384 -> 4)
Trainable parameters: 68,228
Optimiser
Adam, learning rate 0.001
Batch size / epochs
32 / 100

4. Compressive-Sensing CNN (Mo et al., 2022)

Y. Mo, J. Huang and G. Qian, “Deep Learning Approach to UAV Detection and Classification by Using Compressively Sensed RF Signal,” Sensors, vol. 22, no. 8, 3072, 2022.

The waveform is first compressed by a random sensing matrix and the classifier operates directly on the compressed measurements, reducing the data rate that must be acquired and processed.

Sensing
y = Φx, compression ratio 0.5, M = 1024 measurements
Sensing matrix
Deterministic Gaussian random matrix with each row normalised to unit L2 norm (implemented in src/preprocessing/compression.py; the original work uses random demodulation, and its code was not released)
Input (1, 1024)
Conv1d(1 -> 32, k=11, s=2, p=5) + ReLU -> MaxPool1d(2)
Conv1d(32 -> 64, k=5, s=1, p=2) + ReLU -> MaxPool1d(2)
Flatten (8,192) -> Linear(8,192 -> 128) + ReLU -> Linear(128 -> 4)
Trainable parameters: 1,059,908

5. MobileNetV3Small (Compact Spectrogram Baseline)

A compact 2-D CNN in the style of MobileNetV3-Small, operating on an STFT log-spectrogram. It is the smallest model in the comparison and serves as a low-parameter reference point.

Input (1, 65, 61)  STFT: Hann, n_fft=1024, hop=256, 20*log10|STFT|, Z-score
Conv2d(1 -> 16, 3x3, s=2) + BatchNorm + ReLU
Depthwise Conv2d(16 -> 32, 3x3, s=2, groups=16) -> Pointwise Conv2d(32 -> 64, 1x1) + BatchNorm + ReLU
AdaptiveAvgPool2d(1) -> Linear(64 -> 128) + ReLU -> Linear(128 -> 4)
Trainable parameters: 11,588
Optimiser
Adam, learning rate 0.001
Batch size / epochs
32 / 100
