Roadmap

VARDAN is scoped to RF-only research. The remaining work focuses on completing the benchmarks, testing robustness, and closing the gap between segment-level and recording-level performance documented on the Results page.

Table 1. Project phases.
PhaseDescriptionStatusNotebook / code
1Repository scaffolding, configuration and path resolutionCompletedsrc/config.py, src/utils/paths.py, configs/
2RF preprocessing, baseline reproduction and VARDHAN RF modelsIn progressNotebooks 01–05, src/models/
3Remaining baseline benchmarks, ablations and RF robustness experimentsPlannednotebooks/09_Experiments.ipynb, scripts/
4Session-invariant training to close the recording-level generalisation gapPlannedsrc/models/, src/data/

1. Complete the Benchmarks

  • Run the 10-fold segment-level benchmark for DSCNN, CS-CNN and MobileNetV3Small.
  • Run the planned VARDHAN-v2A ablation (Experiments A–D) to measure the contribution of each branch.
  • Re-run the historical strict baselines with the same 50 segments/file and training budget as VARDHAN-v3 for a controlled comparison.

2. Close the Generalisation Gap

  • Session-invariant training: cross-recording augmentation and domain-adversarial objectives.
  • Train on both receiver bands (L and H) so the Phantom class is not tied to a single band.
  • Investigate longer or stitched L+H input windows for the VARDHAN models.

3. RF Robustness Experiments

notebooks/09_Experiments.ipynb is reserved for RF robustness experiments, such as additive noise and interference. It currently contains placeholders only, and no robustness results are reported.

4. Open-Set Evaluation

  • Evaluate rejection of unknown drones and background sources not seen in training.
  • Measure confidence calibration of the classifiers.

5. Software Profiling

Model size and speed are measured in software with profile_model_footprint() and benchmark_inference_latency() in src/benchmark/bench.py. These figures describe the development machine they are run on. Physical deployment on embedded hardware is outside the scope of this project, and no hardware measurements have been made.
