Code and Repository

The source code is available at github.com/Adith1207/Vardan under the MIT License. It is a Python 3.11 / PyTorch research codebase organised as an installable package (pyproject.toml).

5. Installation and Usage

Environment

git clone https://github.com/Adith1207/Vardan.git
cd Vardan
conda env create -f environment.yml
conda activate vardan
# or, without conda:
pip install -r requirements.txt
Table 4. Dependencies (minimum versions).
CategoryPackages

Scientific computingnumpy ≥ 1.24.0, scipy ≥ 1.10.0, pandas ≥ 2.0.0, h5py ≥ 3.8.0, scikit-learn ≥ 1.2.0

Data

Download DroneRF from Mendeley Data and place the extracted folders under data/raw/DroneRF/ (see data/README.md).

Reproducing the main results

# 10-fold segment-level benchmark
python scripts/train_fgcs_faithful_reproduction.py --raw_data_dir data/raw/DroneRF
python scripts/train_baseline1dcnn_faithful_reproduction.py --raw_data_dir data/raw/DroneRF
python scripts/train_vardhan_v3_standardized.py --normalization per_segment --epochs 15 --raw_data_dir data/raw/DroneRF

# Strict recording-level benchmark
python scripts/train_vardhan_v3.py --normalization per_segment --epochs 100 --samples_per_file 50 --splits_dir data/splits --raw_data_dir data/raw/DroneRF

# Quick check without the dataset
python scripts/train_vardhan_v3.py --mock --epochs 1

Tests

The tests/ directory contains 15 pytest modules covering the faithful pipelines, input representations, split diagnostics, trainer checkpointing, configuration loading and the VARDHAN-v2A / v3 models and training scripts. Run with pytest tests/.
