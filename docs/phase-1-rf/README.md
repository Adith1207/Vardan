# Phase 1 – RF-Based Drone Detection

## Objective

Develop a lightweight RF-based drone detection and identification model and evaluate it rigorously on the DroneRF dataset.

## Current Tasks

- Literature Review
- Dataset Analysis
- Signal Visualization
- Baseline Model Reproduction
- Segment-Level and Strict Recording-Level Evaluation
- Software Profiling (parameters, MACs/FLOPs, CPU/GPU latency on a development machine)

Physical embedded-device deployment is out of scope; no hardware measurements have been made.

## Dataset

DroneRF Dataset
